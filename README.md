# ML-Text-classification-sparse-vs-contextual-embeddings
Comparison of sparse text representations and contextual embeddings for text classification using classical machine learning.

## Overview

This project compares traditional sparse text representations (Bag of Words, TF-IDF, and GloVe) with contextual embeddings generated using DistilBERT for multi-class text classification.

The objective is to evaluate how different feature extraction techniques affect the performance of classical machine learning models.

---

## Features

- Text preprocessing
- Bag of Words (BoW)
- TF-IDF
- GloVe embeddings
- DistilBERT embeddings
- Logistic Regression
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- PCA
- Truncated SVD

---

## Technologies Used

- Python
- Scikit-learn
- PyTorch
- Hugging Face Transformers
- NumPy
- Pandas
- NLTK
- Matplotlib

---

## Results

- Compared traditional sparse features with contextual embeddings.
- DistilBERT embeddings achieved the highest classification performance.
- Evaluated models using Accuracy and Macro F1-score.
